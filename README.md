# Overview

To learn more on how to use C++, I've created a simple inventory program that utilizes the following:
Variables
Experssions
Conditionals
Loops
Functions
Classes
A data structure from STL, in this case a vector.

Software used:
VSCode with extensions:
C/C++
C/C++ DevTools
C/C++ Extension Pack
C/C++ Themes (UI Themes)
Visual Studio (Microsoft) for compiling C++ Code.

The upurpose of writing this software is to learn C++ and utilize my current understanding of how to
write code, as well as demonstrate that understanding by putting it to work.
